# 📄 DocuMind AI

## 🚀 Overview

DocuMind AI is an intelligent document analysis system that extracts meaningful insights from PDF documents. It combines Natural Language Processing (NLP) and rule-based techniques to provide summaries, entity extraction, and sentiment analysis.

---

## ✨ Features

* 📄 PDF Text Extraction
* 🧠 AI-Based Text Summarization (limited to 100 words)
* 🔍 Entity Extraction:

  * 👤 Names
  * 📅 Dates (multiple formats supported)
  * 🏢 Organizations
  * 💰 Monetary values
* 😊 Sentiment Analysis (Positive / Negative / Neutral)
* 🎯 Clean and interactive UI using Streamlit

---

## 🛠️ Tech Stack

* Python
* Streamlit
* PyPDF2
* spaCy
* Sumy (LSA Summarizer)
* TextBlob
* Regex (for rule-based extraction)

---

## 🧠 Architecture

1. PDF Upload
2. Text Extraction
3. Text Cleaning
4. NLP Processing:

   * Summarization
   * Entity Extraction
   * Sentiment Analysis
5. Structured Output via UI
